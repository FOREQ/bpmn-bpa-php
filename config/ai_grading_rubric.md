Критерии, по которым ИИ предлагает баллы за BPMN-схему.
Файл можно править: он целиком подставляется в инструкцию для модели.

1. Участники (≈20% балла): все исполнители из текста выделены отдельными дорожками
   (или пулами для внешних участников); действия стоят в дорожке того, кто их выполняет.
2. Задачи (≈30%): все существенные действия из текста есть на схеме; подписи —
   глагол в неопределённой форме + объект («Проверить заявку»); нет лишних действий,
   которых нет в тексте.
3. Логика и порядок (≈25%): последовательность совпадает с текстом; ветвления
   оформлены шлюзами нужного типа (исключающее «или» для выбора, «и» для параллельной
   работы), выходы шлюза подписаны условиями, ветки корректно сливаются или завершаются.
4. События (≈15%): есть стартовое событие и конечное событие для каждой ветки;
   тип события соответствует смыслу (сообщение, таймер и т.д.), где это следует из текста.
5. Корректность нотации (≈10%): нет «висящих» элементов без входа/выхода,
   потоки управления не пересекают границы пулов (между пулами — потоки сообщений).

Допустимо: другие формулировки, объединение двух мелких шагов в один, иной, но
логически эквивалентный порядок оформления. Не снижай балл за расположение элементов.
Если схема почти пустая или не относится к заданию — 0–20% от максимума.
